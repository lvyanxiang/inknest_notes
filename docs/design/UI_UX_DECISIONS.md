# InkNest UI/UX Decisions

Record accepted, reusable interaction or visual patterns here. Feature-specific
details belong in `docs/product/features/<feature-slug>/UI_UX_SPEC.md`.

| Date | Pattern | Accepted decision | Status | Artifact |
|---|---|---|---|---|
| 2026-08-19 | Canvas-object text editing | Keep idle typed text chrome-free; use first-tap selection, second-tap editing, an external 44px object toolbar, direct horizontal resizing for wrapping, and explicit font/size/color/alignment controls in both editor layouts. | Delivered | `docs/product/features/text-box-font-and-resize/UI_UX_SPEC.md` |
| 2026-08-18 | Editor content search removal | Remove Search from the editor document bar and remove its sheet, progress, result, navigation, and highlight states. Let the document context use the reclaimed space; retain library search and lasso-context Smart Ink. | Delivered | `docs/product/features/local-content-recognition/UI_UX_SPEC.md` |
| 2026-08-18 | Fixed-layout Smart Ink replacement | Smart Ink may change glyph appearance but not the selected handwriting's layout footprint: fit measured glyph ink inside the existing selection, preserve explicit lines, and leave surrounding strokes untouched. | Delivered | `docs/product/features/local-content-recognition/UI_UX_SPEC.md` |
| 2026-08-17 | Background recognition in search | Keep PDF and image OCR implicit in the existing notebook Search sheet; preserve editing state, label image results, and reuse result navigation/highlights. Keep Smart Ink model preparation inside its existing confirmation dialog with manual correction fallback. | Superseded 2026-08-18: editor search and raster OCR removed; Smart Ink retained | `docs/product/features/local-content-recognition/UI_UX_SPEC.md` |
| 2026-08-06 | Optional account entry | Keep the library as startup and expose Account from its header; use one responsive sign-in/create-account page with inline validation and non-blocking session restoration, while sign-out affects cloud identity only. | Delivered | `docs/product/features/inknest-cloud-backend/UI_UX_SPEC.md` |
| 2026-08-06 | Recently deleted recovery | Keep ordinary deletion non-blocking and reversible; expose active Tombstones through Recently Deleted, and report delete-versus-edit preservation as sync status instead of interrupting writing. | Notebook and arbitrary-page App recovery plus delete/edit status delivered | `docs/product/features/inknest-cloud-backend/UI_UX_SPEC.md` |
| 2026-08-06 | Conflict recovery | Surface background sync conflicts through persistent sync status instead of interrupting writing; show device/time as metadata and offer Keep Original, Use Conflict Version, and emphasized Keep Both in an accessible detail sheet. | Delivered | `docs/product/features/inknest-cloud-backend/UI_UX_SPEC.md` |
| 2026-08-04 | Cross-layout editor tools | Keep shared tools and labels consistent between paged and infinite notebooks; adapt coordinates and selection behavior instead of hiding capabilities that do not depend on pages. | Delivered | `docs/product/features/infinite-canvas-v1/UI_UX_SPEC.md` |
| 2026-08-03 | Notebook layout modes | Choose Paged notebook or Infinite canvas before creation; use a focused world-coordinate canvas editor without page-only controls and preserve exclusive Pencil/finger gesture ownership. | Delivered | `docs/product/features/infinite-canvas-v1/UI_UX_SPEC.md` |
| 2026-08-03 | Editor command hierarchy | Use a compact pager, separate Pages / Outline / Bookmarks panels, and paper-style-first blank-page insertion; keep page actions out of More and adapt Record/Export shortcuts to width. | Delivered | `docs/product/features/editor-workspace-v2/UI_UX_SPEC.md` |
| 2026-07-27 | Collapsible editor zoom chrome | Keep a quiet Fit-Width-relative zoom chip that expands on demand, show a transient center zoom badge while zooming, and expose Fit Width / Fit Page from More → View as well as the zoom menu. | Delivered | `docs/product/features/editor-workspace-polish/UI_UX_SPEC.md` |
| 2026-07-18 | Unified spine bookshelf library | Keep gapless page-weighted spines at a shared 3-degree left lean; tap briefly pulls and scales a notebook before opening, while long press, hover, or focus holds inspection and tips only truncated titles. | Delivered | `docs/product/features/library-bookshelf-home/UI_UX_SPEC.md` |
