# Contributing to InkNest Notes

Thank you for helping improve InkNest Notes.

## Before opening a pull request

1. Open an issue or discussion before a large or behavior-changing patch.
2. Keep secrets, credentials, production data, user notebooks, and signing
   material out of commits.
3. Include tests and update relevant project documentation.
4. Identify every copied or generated third-party file and its license.
5. Run `flutter test`, `flutter analyze`, and the relevant server checks.

## Licensing of contributions

All contributions require agreement to [CLA.md](CLA.md). By checking the CLA
confirmation in the pull-request template and submitting the pull request, you
agree to that version of the CLA for the submitted Contribution.

Accepted software contributions are published in the community edition under
`AGPL-3.0-only`. Documentation contributions are handled according to
[LICENSING.md](LICENSING.md). The CLA also allows the Project Owner to maintain
separately licensed official editions.

Do not submit code or assets that you cannot license on these terms. A
Developer Certificate of Origin sign-off by itself does not replace the CLA.

## Branding

Contribution does not grant a right to use InkNest branding. See
[TRADEMARKS.md](TRADEMARKS.md).
